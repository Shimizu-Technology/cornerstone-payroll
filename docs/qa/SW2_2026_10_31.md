Root cause: SW-2 deliberately drew empty strings into both employee address lines. SSN lookup/decryption already worked for stored values. The official template has irregular per-row rectangles and a separate ZIP column. This change uses the exact widgets, adds street/unit and city/state/ZIP, and fills the ZIP column. Text shrinks to 6pt; exceptionally long single-line values end with an ellipsis rather than crossing adjacent boxes. Partial addresses print available details.

The annual W-2GU export is a preparation PDF, not an official employee copy. Its dataset already carried full addresses but the PDF table omitted them; addresses now appear under each employee name. Its SSNs remain intentionally masked. Form 500 has employer details only; no employee identity fields apply. W-3SS readiness uses the same annual review. No separate official W-2/W-2GU employee-copy generator exists in this branch.
